TELEGRAM

Configure a integracao com Telegram para seus agentes

1. CONFIGURAR BOT TOKEN

Crie um bot no Telegram via @BotFather e insira o token abaixo.

2. CONFIGURAR WEBHOOK

Configure o webhook para receber mensagens do Telegram.

3. COMANDOS DO BOT

Seu bot Telegram responde aos seguintes comandos:

/start - Mensagem de boas-vindas /agents - Listar agentes disponiveis /link <id> - Conectar a um agente especifico /status - Ver status do agente conectado

4. AGENTES CONECTADOS

Nenhum agente conectado ao Telegram ainda.

5. TESTAR ENVIO

Envie uma mensagem de teste para um chat do Telegram.

API REFERENCE

Documentacao da API para integracao com seus agentes

AUTENTICACAO

Use a API key do seu agente no header Authorization:

Authorization: Bearer sk-seed-xxxxxxxxxxxxxxxxx
ENDPOINTS
GET /api/agents/
Listar todos os agentes
POST /api/agents/
Criar novo agente
{ "name": "MEU AGENTE", "description": "Assistente personalizado", "agent_type": "assistant", "system_prompt": "Voce e um assistente profissional...", "personality": { "tone": "professional", "language": "pt-BR", "formality": "formal", "empathy_level": 7 }, "context": "Contexto do negocio..." }
POST /api/agents/quick
Criar agente rapidamente com parametros simples
?name=MeuAgente&description=Assistente&system_prompt=Seja+util
GET /api/agents/{agent_id}
Detalhes de um agente especifico
PUT /api/agents/{agent_id}
Atualizar configuracao do agente
DELETE /api/agents/{agent_id}
Remover agente
POST /v1/agents/chat/completions
Conversar com um agente (formato OpenAI-compatible)
{ "agent_id": "uuid-do-agente", "messages": [ {"role": "user", "content": "Ola, preciso de ajuda"} ], "stream": false }
GET /v1/agents/models
Listar agentes disponiveis como modelos
WORKFLOW API
POST /api/workflows/
Iniciar novo workflow de criacao de agente
POST /api/workflows/{id}/chat
Conversar com o workflow engine
POST /api/workflows/{id}/create-agents
Criar agentes a partir do workflow completado
TELEGRAM API
POST /api/telegram/webhook
Endpoint de webhook do Telegram
POST /api/telegram/setup
Configurar webhook do Telegram
GET /api/telegram/status
Status da integracao Telegram
POST /api/telegram/send
Enviar mensagem direta via Telegram
