# AI HOST — Principios de Cinematografia para IA

## Por que isso importa

O agente precisa entender cinematografia pra:
1. Gerar imagens com composicao profissional (Nano Banana Pro)
2. Animar imagens com intencao narrativa (Veo 3.1)
3. Estruturar edicao com ritmo cinematografico (Remotion)
4. Criar thumbnails que convertem
5. Guiar o enquadramento do usuario durante lives

---

## 1. Enquadramento (Shot Types)

### Por distancia

| Shot | Descricao | Quando usar | Prompt hint |
|------|-----------|-------------|-------------|
| **ECU** (Extreme Close-Up) | So olho, boca, detalhe | Emocao intensa, revelar detalhe | "extreme close-up of eye, macro lens" |
| **CU** (Close-Up) | Rosto inteiro | Emocao, conexao, reacao | "close-up portrait, 85mm lens, f/1.4" |
| **MCU** (Medium Close-Up) | Cabeca e ombros | Entrevista, dialogo | "medium close-up, head and shoulders" |
| **MS** (Medium Shot) | Cintura pra cima | Conversa, apresentacao | "medium shot, waist up, natural pose" |
| **MLS** (Medium Long Shot) | Joelho pra cima | Acao moderada, contexto corporal | "medium long shot, knee up" |
| **LS** (Long Shot) | Corpo inteiro | Contexto, localizacao | "full body shot, wide environment" |
| **ELS** (Extreme Long Shot) | Pessoa minuscula na paisagem | Escala, solidao, epico | "extreme wide shot, vast landscape, tiny figure" |

### Por angulo

| Angulo | Efeito | Prompt hint |
|--------|--------|-------------|
| **Eye Level** | Neutro, natural | "eye level camera angle" |
| **High Angle** | Vulnerabilidade, submissao | "high angle shot, looking down" |
| **Low Angle** | Poder, autoridade, grandeza | "low angle shot, looking up, heroic" |
| **Dutch Angle** | Tensao, desorientacao | "dutch angle, tilted frame" |
| **Bird's Eye** | Onisciencia, padrao, mapa | "bird's eye view, top down" |

## 2. Composicao

### Regras fundamentais

| Regra | O que e | Prompt hint |
|-------|---------|-------------|
| **Regra dos Tercos** | Sujeito nos intersectos do grid 3x3 | "rule of thirds composition" |
| **Linhas Guia** | Linhas naturais levam o olho ao sujeito | "leading lines pointing to subject" |
| **Moldura Natural** | Elementos do cenario enquadram o sujeito | "natural frame, doorway/arch framing subject" |
| **Simetria** | Espelhamento perfeito | "symmetrical composition, centered" |
| **Espaco Negativo** | Grande area vazia com sujeito pequeno | "negative space, minimalist, subject small in frame" |
| **Profundidade** | Foreground + midground + background | "layered composition, depth, foreground elements" |
| **Proporcao Aurea** | Espiral de Fibonacci | "golden ratio composition, fibonacci spiral" |
| **Triangulo** | 3 pontos de interesse formando triangulo | "triangular composition" |

### Para thumbnails YouTube

| Principio | Aplicacao |
|-----------|-----------|
| Rosto grande | Close-up ou MCU com expressao forte |
| Contraste alto | Cores vibrantes vs fundo escuro |
| Texto legivel | Maximo 4-5 palavras, fonte bold |
| 1 focal point | Um unico ponto de atencao |
| Espaco pro texto | Deixar area limpa pra titulo |
| Emocao clara | Surpresa, raiva, alegria — exagerado |

## 4. Movimento de Camera

### Movimentos classicos

| Movimento | Efeito | Uso |
|-----------|--------|-----|
| **Pan** (horizontal) | Revela cenario, segue acao | Panoramica, transicao |
| **Tilt** (vertical) | Revela altura, poder | Revelar predio, personagem |
| **Dolly In** | Aproxima do sujeito, intimidade | Momento importante |
| **Dolly Out** | Afasta, revela contexto | Conclusao, solidao |
| **Truck** (lateral) | Move ao lado do sujeito | Acompanhar caminhada |
| **Crane/Jib** | Move pra cima/baixo + frente/tras | Epico, revelar cenario |
| **Steadicam** | Segue sujeito suavemente | Imersao, perseguicao |
| **Handheld** | Instavel, urgente | Documentario, tensao |
| **Zoom** | Aproxima/afasta opticamente | Revelar, choque |
| **Dolly Zoom** (Vertigo) | Fundo expande/comprime | Desorientacao, revelacao |

### Para animacao de imagens (Veo 3.1)
Quando usar `generate_video_from_image`, descrever o movimento:
```
"Slow dolly in toward the subject's face,
soft rack focus from background to foreground,
subtle camera shake for organic feel"
```

## 8. Ritmo de Edicao

### Principios de corte

| Principio | Regra | Aplicacao no Remotion |
|-----------|-------|----------------------|
| **Corte na acao** | Corta durante movimento, nao depois | Transicao durante animacao, nao em frame estatico |
| **Regra dos 180 graus** | Camera sempre do mesmo lado da acao | Manter consistencia de direcao entre shots |
| **Match cut** | Forma/movimento similar entre 2 shots | Transicao de forma (circulo → sol) |
| **J-cut** | Audio do proximo shot comeca antes do visual | Iniciar audio 0.5s antes da transicao visual |
| **L-cut** | Audio do shot anterior continua no proximo | Manter audio 0.5s depois da transicao visual |
| **Jump cut** | Corte abrupto, pula tempo | Acelerar ritmo, YouTube style |
| **Smash cut** | Contraste abrupto (calmo → caos) | Impacto, humor, revelar |
| **Montagem** | Sequencia rapida de shots | Resumir processo, passagem de tempo |

### Ritmo por tipo de conteudo

| Tipo | Duracao media de shot | Ritmo |
|------|----------------------|-------|
| Tutorial calmo | 5-10 segundos | Lento, respirado |
| Vlog dinamico | 2-4 segundos | Medio, variado |
| Shorts/Reels | 1-2 segundos | Rapido, punch |
| Cinematic | 3-8 segundos | Variado, intencional |
| Hype/trailer | 0.5-1.5 segundos | Ultra rapido |

## 9. Prompt Templates Prontos

### Thumbnail YouTube
```
Close-up portrait of [pessoa/personagem], looking directly at camera
with [emocao: shock/excitement/curiosity] expression,
85mm lens f/1.4, shallow depth of field,
[warm/cool] cinematic lighting, rim light separating from
[dark/blurred] background, high contrast,

16:9 aspect ratio, 4K resolution
```

```
Cinematic [subject] shot,
[camera movement: slow dolly in / tracking / crane down],
anamorphic lens flare, shallow depth of field,
[lighting: golden hour / blue hour / Rembrandt],
[color grade: teal and orange / desaturated / warm],
```

## 10. Como o Agente Usa Isso

### Na geracao de imagens (Nano Banana Pro)
- Sempre especificar: lente, abertura, iluminacao, composicao, aspect ratio
- Usar referencia de estilo de diretor quando apropriado
- Manter consistencia de estilo entre assets do mesmo video

### Na animacao de imagens (Veo 3.1)
- Descrever movimento de camera, nao so o que acontece
- Especificar duracao e ritmo
- Manter direcionalidade consistente (regra dos 180 graus)

### Na edicao (Remotion)
- Aplicar ritmo de corte adequado ao tipo de conteudo
- Usar J-cuts e L-cuts pra transicoes suaves
- Match cuts entre shots similares
- Variar enquadramento a cada corte (wide → close → medium)

### No live (OBS)
- Sugerir enquadramento pro usuario (posicao da camera, iluminacao)
- Avatar posicionado respeitando regra dos tercos
- HUD com layout limpo, espaco negativo, hierarquia visual

### Nas thumbnails
- Rosto grande + emocao clara + espaco pra texto
- Contraste alto, cores vibrantes
- Maximo 4-5 palavras de texto overlay
